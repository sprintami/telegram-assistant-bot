# Личный ассистент-бот (Telegram)

Что это: Telegram-бот только для вас (Булат) — оперативный чат с Claude, память о вас (профиль + история), и кнопка со ссылкой на верстак (страницу с ролями-агентами — Дизайнер, Финансист, Юрист, Маркетолог — которую вы уже сделали как отдельный артефакт). Подключение ChatGPT отложено — сейчас работает только Claude.

## Как это устроено (коротко)

- **`src/bot.ts`** — сам бот: команды, кнопка, обработка сообщений.
- **`src/db.ts`** — хранилище: SQLite-файл (профиль, история сообщений, резюме). Простая база в одном файле — не нужен отдельный аккаунт/сервис базы данных.
- **`src/ai.ts`** — вызовы Claude.
- **`src/memory.ts`** — автоматическое сжатие старой истории в резюме, чтобы не раздувать контекст (и счёт за API).

## Запуск с нуля

1. **Токен бота** — уже есть от @BotFather.
2. **Ваш Telegram ID** — написать [@userinfobot](https://t.me/userinfobot), он пришлёт число.
3. **Ключ Claude API** — https://console.anthropic.com/settings/keys → Create Key.
4. Скопировать `.env.example` в `.env`, заполнить все значения.
5. Установить зависимости и запустить локально для проверки:
   ```
   npm install
   npm run dev
   ```
6. Написать боту в Telegram `/start`.

## Деплой на Railway

1. Код должен лежать в GitHub-репозитории — Railway разворачивает оттуда.
2. Создать сервис в Railway → Deploy from GitHub repo → выбрать репозиторий.
3. В Variables сервиса добавить: `BOT_TOKEN`, `OWNER_TELEGRAM_ID`, `ANTHROPIC_API_KEY`, `VERSTAK_WEBAPP_URL`, `DB_PATH=/app/data/bot.db`.
4. Подключить volume (постоянный диск) к пути `/app/data` — иначе память бота будет стираться при каждом обновлении кода.
5. Start command: `npm run build && npm start`.
